Cardiovascular Risk Prediction and Explanation

Prediction et Explication du Risque Cardiovasculaire

Nightingale Heart Project · JGU University, Mainz

42,377patient recordsdonnees patients
78%risk reduction (9 cases)reduction du risque
RESTAPI in productionAPI en production

A cardiovascular risk prediction system trained on 42,377 patients from the European Social Survey. Generates clinically valid counterfactual explanations (MOC algorithm) that tell clinicians not just the predicted risk, but the minimal lifestyle changes needed to reduce it. Deployed as a production REST API with a React frontend and a multi-calculator comparison dashboard (SCORE2, PREVENT, WHO).

Systeme de prediction du risque cardiovasculaire entraine sur 42 377 patients. Genere des explications contrefactuelles cliniquement valides (algorithme MOC) indiquant les modifications minimales de style de vie pour reduire le risque. Deploye comme API REST en production avec un frontend React et un tableau de bord de comparaison multi-calculateurs.
